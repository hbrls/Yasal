# Intent 标准分流

**适用位置**：`RUNBOOK.md` 步骤 6。

**目标文件**：`raw0/{一级目录}/Intent.md`。

## 什么是 Intent（意图/身份类）

描述 Agent 是谁、叫什么，以及最顶层任务目标的极简表达。

Intent 只回答“是什么”或“最顶层要做什么”，不描述执行方法、工具、流程、条件或结果判断。

### 典型归入

```text
You are an agent.
Your name is Claude.
You are a coding agent.
You help users accomplish tasks.
```

### 不属于 Intent

- 具体行为要求、操作步骤或工具用法
- 带有条件逻辑、例外、重试或停止条件的指令
- 对验证、审查、协作或输出格式的详细要求
- 只是声明 Agent 采用某种语气或态度的内容

如果身份声明后附带行为细节，只抽取纯粹的身份或顶层使命句，其余内容原地保留。

## 判断测试

把句子压缩为“Agent 是谁”或“Agent 的最高层目标是什么”：

- 压缩后仍保持完整且不需要补充执行细节 → 归入 Intent
- 必须补充工具、步骤、条件、证据或输出格式才能表达完整含义 → 不归入 Intent

例如：

```text
You are an agent whose mission is to verify results.
```

其中顶层使命可以归入 Intent；如果文本继续规定使用哪些测试、如何取证或何时报告失败，则那些句子流向 Verification 或后续类别。

## 执行方式

**前置检查**：若当前工作文件无内容，立即跳过本步骤，停止执行。正常分流时，当前工作文件是 Unclassified 文件；尾部回溯时，当前工作文件由任务明确指定。

从当前工作文件中逐句（或逐句组）做语义判断：“这段内容属于 Intent 吗？”

- 属于 → 抽走，并从当前工作文件中删除对应内容
- 不属于 → 保留原位，不推断它属于哪个后续类别，不做任何标注

若抽出了 Intent 内容：

- 目标文件已存在时，读取完整现有内容，在末尾追加 `---`、`## 来源：{原文件名}` 和抽出内容；不得改动既有文字
- 目标文件不存在时，创建文件并写入 `## 来源：{原文件名}` 和抽出内容

若未抽出任何 Intent 内容，跳过，不创建目标文件。
